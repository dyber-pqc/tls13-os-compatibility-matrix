## Notes

- Backport caveat: enterprise distributions patch fixed package versions in place. A host reporting OpenSSL 1.1.1 on RHEL 8 is patched; the same string on an abandoned build may not be. Capability detection should test protocol negotiation, not version strings alone.
- The dividing line for nearly all Linux is OpenSSL 1.1.1 (released 2018-09), the first release with RFC 8446 TLS 1.3. Any distribution whose system OpenSSL predates 1.1.1 cannot offer native TLS 1.3 without a major version move.
- Open stretch goals for contributors: HPC distros, NAS operating systems (Synology DSM, QNAP QTS; see Network Appliances tab), Gentoo, NixOS, and vendor-embedded Linux derivatives.
