## Notes

- Appliances need per-plane, per-feature rows: management UI, data-plane proxying or decryption, VPN termination, and cloud service call-home each adopt TLS versions on separate schedules. A single yes/no per box is meaningless and this tab deliberately refuses to give one.
- TLS-inspecting middleboxes below their capable release do not just lag: they actively cap or break TLS 1.3 for everything behind them. Inventory these first; they set the ceiling for entire segments.
