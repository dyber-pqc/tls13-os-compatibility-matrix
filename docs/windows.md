## Notes

- Everything riding Schannel inherits the OS ceiling: .NET Framework, IIS, HTTP.sys, RDP, LDAPS, WinHTTP. Applications that bundle their own TLS stack (browsers, Java, applications shipping OpenSSL) can exceed the OS ceiling on the same host.
- Secondary sources conflict on Windows TLS 1.3 minimums (some claim Server 2016 or Windows 10 1903). Microsoft's own Schannel documentation is unambiguous: Windows 11 and Windows Server 2022 are the floor. This conflict is itself evidence of why a vetted matrix is needed.
- LTSC editions are where lifecycle vs capability mismatches concentrate: they are chosen precisely for longevity, and the Windows 10 based ones are frozen below the TLS 1.3 line for their entire lives.
